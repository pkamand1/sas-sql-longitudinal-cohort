# Metformin adherence and HbA1c trajectories: a SQL and SAS longitudinal cohort analysis

This repository works through a small observational study from start to finish, in the form in which such studies usually arrive: as an extract from an electronic health record, with a patient table, a laboratory table, and a pharmacy dispensing table, each carrying the inconsistencies that real clinical data carry. MySQL is used to profile the extract, document and apply data quality decisions, and construct the analytic cohort, including a proportion-of-days-covered measure of medication adherence derived from pharmacy fills. SAS is then used to describe the cohort, model HbA1c trajectories with a linear mixed model, model glycaemic control at twelve months with logistic regression, and assemble the tables and a figure into a single report.

The question is a familiar one in pharmacoepidemiology: among adults with type 2 diabetes who start metformin, do patients who refill reliably during the first year see a faster fall in HbA1c, and are they more likely to reach an HbA1c below 7.0% at twelve months?

## The data are synthetic

No real patient data appear anywhere in this repository. The extract in `data/` is generated by `scripts/generate_data.py` from a model whose parameters are known, which means that the analysis can be checked against the truth rather than merely run:

| Feature of the generating model | True value |
| --- | --- |
| Mean HbA1c change per month, adherent patients (PDC of at least 0.80) | -0.050 percentage points |
| Mean HbA1c change per month, less adherent patients | -0.015 percentage points |
| Patient-specific variation | random intercepts and slopes, plus measurement error |

The generator also plants the kinds of problems that a careful analyst should catch before modelling anything: exact duplicate laboratory rows, HbA1c values that are physiologically impossible, results reported in mmol/mol rather than percent, results dated after the extract date, pharmacy fills dated before the patient joined the practice, and missing sex.

## Repository layout

```
data/                        synthetic extract: patients.csv, labs.csv, pharmacy_fills.csv
scripts/generate_data.py     regenerates the extract (fixed random seed)
scripts/run_sql.sh           runs the SQL steps in order and exports the analytic tables
sql/01_schema.sql            raw tables
sql/02_load.sql              LOAD DATA from the CSV extract
sql/03_quality_checks.sql    profiles the raw data and records each finding in qc_log
sql/04_clean.sql             deduplication, unit standardization, exclusions (window functions, CTEs)
sql/05_cohort.sql            index date, baseline, follow-up, adherence (recursive CTE), outcome, cohort flow
sas/main.sas                 runs the SAS programs below and writes output/sas_results.pdf
sas/01_import_clean.sas      DATA step import with explicit informats, derivations, MERGE, PROC SQL checks
sas/02_table1.sas            Table 1 by adherence group from two macros (PROC MEANS, PROC FREQ, PROC REPORT)
sas/03_mixed_model.sas       PROC MIXED with random intercepts and slopes, ESTIMATE statements
sas/04_logistic.sas          PROC LOGISTIC for HbA1c below 7.0% at twelve months
sas/05_figure.sas            mean trajectories with confidence bands (PROC SGPLOT)
output/                      analytic data sets exported by the SQL steps, and the SAS report
```

## How to run

1. SQL (MySQL 8.0 or later, with `local_infile` enabled on the server). From the repository root:

   ```
   bash scripts/run_sql.sh -u <user> -p
   ```

   This creates the `ehr_cohort` database, runs the five SQL files in order, and writes `analytic_patient.csv`, `analytic_long.csv`, `qc_log.csv`, and `cohort_flow.csv` to `output/`. These exports are also committed, so the SAS step can be run without MySQL.

2. SAS (SAS 9.4 or SAS OnDemand for Academics). Place the repository in your home directory, or edit `ROOT` at the top of `sas/main.sas`, then submit:

   ```
   %include "~/sas-sql-longitudinal-cohort/sas/main.sas";
   ```

   The report is written to `output/sas_results.pdf`.

## Data quality findings

The checks in `sql/03_quality_checks.sql` find the following in the raw extract, and each finding is recorded in `qc_log` together with the action taken:

| Check | Rows | Action |
| --- | --- | --- |
| Duplicate laboratory rows beyond the first copy | 25 | Keep the row with the lowest `lab_id` |
| HbA1c reported in mmol/mol | 12 | Convert to percent (value / 10.929 + 2.15) |
| HbA1c in percent outside 3 to 20 | 8 | Exclude |
| Results dated after the extract date | 5 | Exclude |
| Fills dated before practice enrollment | 6 | Exclude |
| Missing sex | 9 | Retain; reported as missing in Table 1 and excluded from adjusted models |
| Records without a matching patient | 0 | Exclude |

## Cohort construction

| Step | Patients |
| --- | --- |
| Patients in the extract | 600 |
| With at least one valid metformin fill | 600 |
| With a baseline HbA1c in the 90 days before the index fill | 597 |
| With at least one follow-up HbA1c (analytic cohort) | 597 |
| With a twelve-month HbA1c (logistic regression cohort) | 557 |

Of the 597 patients in the analytic cohort, 273 were adherent (PDC of at least 0.80) and 324 were not, and the long data set holds 2,883 HbA1c results.

## Methods in brief

The index date is the first valid metformin fill. Baseline HbA1c is the most recent result in the 90 days before the index date, follow-up results are those between day 1 and day 456, and the twelve-month value is the result closest to day 365 within days 274 to 456. Adherence is the proportion of days covered over days 0 to 364, computed by expanding each fill across the calendar days it supplies with a recursive common table expression so that overlapping fills are counted once. The mixed model regresses HbA1c on months since the index date, adherence, and their interaction, adjusting for age and sex, with correlated random intercepts and slopes for each patient and Kenward-Roger degrees of freedom; ESTIMATE statements report the monthly change in each group and their difference. The logistic model estimates the odds of an HbA1c below 7.0% at twelve months by adherence, adjusting for baseline HbA1c, age, and sex.

Because the data are simulated, the mixed model's estimated monthly changes can be compared directly with the true values of -0.050 and -0.015 percentage points per month.

## Limitations

The proportion of days covered here does not shift the start of a fill that overlaps an earlier one, which some definitions do, and it assumes that every dispensed day was taken. The synthetic data contain no confounding by indication, no informative loss to follow-up, and no competing medications, all of which a real analysis of this question would need to address.
